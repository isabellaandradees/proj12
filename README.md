# Exercícios de Vetores em JavaScript

## Descrição

Este repositório contém a resolução de três exercícios utilizando vetores, estruturas de repetição e estruturas condicionais em JavaScript, sem o uso de funções específicas para arrays.

## Exercício 1
Programa que lê a idade de 8 pessoas, armazena em um vetor e calcula a média das idades.

## Exercício 2
Programa que lê a idade de 7 pessoas, armazena em um vetor e exibe as posições das pessoas que possuem mais de 25 anos.

## Exercício 3
Programa que lê 15 números, armazena em um vetor, exibe todos os valores digitados e mostra as posições dos números que são múltiplos de 10.
